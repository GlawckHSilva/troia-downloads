# Downloads do Sistema Tróia

Repositório público usado pelo Assistente Tróia para consultar o catálogo e baixar versões e componentes oficiais.

- Os executáveis ficam exclusivamente nos assets das Releases.
- O arquivo `manifest.json` contém URLs, tamanhos e hashes SHA-256.
- Uma versão publicada não deve ter seu arquivo substituído; publique uma nova Release.
